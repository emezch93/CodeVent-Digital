Deployment & Setup Guide

Configure the Worker URL below so this console can communicate with your backend.

Manual Deployment Steps (Cloudflare Dashboard)

  1. Create a Worker in Cloudflare Dashboard (e.g., codevent-api).
  2. Copy the code from worker/index.js (provided separately) into the Worker's Quick Edit and Deploy.
  3. Create a D1 Database (e.g., codevent-db).
  4. Run the SQL from worker/schema.sql in the D1 Console.
  5. In Worker Settings → Bindings, add a D1 Database binding named exactly DB.
  6. In Worker Settings → Variables, add: FIREBASE_PROJECT_ID, FIREBASE_API_KEY, and ADMIN_EMAILS (comma-separated).
  7. In Worker Settings → Variables (as Secrets), add: ZOHO_CLIENT_ID, ZOHO_CLIENT_SECRET, ZOHO_REFRESH_TOKEN, ZOHO_ACCOUNT_ID.
  8. Paste your Worker URL above and save. Log in to test.
